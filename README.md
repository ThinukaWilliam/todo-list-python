# To-Do List App

A simple desktop to-do list application built with Python and Tkinter, 
developed as part of a university assignment.

## Features
- Add, view, and delete tasks through a graphical interface
- Tasks are saved to a text file, so your list persists between sessions
- Lightweight and easy to run — no external dependencies beyond Python's 
  standard library

## Tech Stack
- Python
- Tkinter (GUI)
- File I/O (text file storage)

## How to Run

```bash
python main.py
```

Make sure Python 3 is installed on your system.

## Future Improvements
- Add task categories/priorities
- Add due dates and reminders
- Switch storage from text file to a database (e.g. SQLite)
